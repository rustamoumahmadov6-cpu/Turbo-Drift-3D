# ✈️ Sky Ace 3D - Ultimate Edition

Бозии ҳаяҷонбахши сеченакаи парвоз дар осмон, ки бо истифода аз **HTML5**, **JavaScript** ва китобхонаи қудратманди **Three.js** сохта шудааст! 

🌐 **Линки бозӣ (Demo):** [Онро дар инҷо бозӣ кунед](https://[USERNAME].github.io/turbo-drift-3d/) *(Лутфан номи корбарии худро ба ҷои [USERNAME] гузоред)*

---

## 🎮 Хусусиятҳои асосии бозӣ
* **Графикаи 3D:** Саҳнаи осмони офтобӣ, замини сабз, кӯҳҳо ва сохти пурраи сеченакаи самолёт.
* **Системаи Имтиёзҳо (Score):** Ҳар қадар пештар равед, имтиёзи шумо бештар мешавад.
* **Тангаҳои Тиллоӣ:** Дар роҳ тангаҳо ҷамъ кунед ва имтиёзи худро зиёд кунед!
* **Системаи Ҷонҳо (Lives):** Самолёт 3 ҷон дорад; ҳангоми бархӯрд бо монеаҳо ҷон кам мешавад.
* **Суръати динамикӣ:** Бо гузашти вақт суръати парвоз зиёд шуда, бозӣ боз ҳам мушкилтар ва шавқовартар мегардад.

---

## 🕹️ Идоракунӣ (Controls)
Бозӣро ба осонӣ бо клавиатураи компютер идора кардан мумкин аст:

* **W** ё **Стрелкаи боло** ⬆️ — Самолёт ба боло меравад
* **S** ё **Стрелкаи поён** ⬇️ — Самолёт ба поён меравад
* **A** ё **Стрелкаи чап** ⬅️ — Гардиш ба чап
* **D** ё **Стрелкаи рост** ➡️ — Гардиш ба рост

---

## 🛠️ Технологияҳои истифодашуда
* **HTML5 Canvas / CSS3** — Барои сохт ва тарҳрезии саҳифа
* **JavaScript (ES6+)** — Барои мантиқи бозӣ, физика ва идоракунӣ
* **Three.js** — Барои коркард ва намоиши графикаи сеченака (WebGL)
